# Закон Бенфорда: первые наработки

Хочу понять, почему в некоторых данных первые цифры распределены по закону Бенфорда, а в других нет.

В коде сравниваются население и годы основания городов, ВВП стран и финансовые показатели компаний. Для каждого набора строится график первых цифр и считается MAD - среднее абсолютное расхождение наблюдаемых долей с законом Бенфорда. Ещё есть два эксперимента: случайный рост чисел и игра Моррисона.

## Как запустить

В папку `data/` нужно положить:

- `city.csv` из [hflabs/city](https://github.com/hflabs/city);
- `gdp.csv` из [datasets/gdp](https://github.com/datasets/gdp);
- `constituents-financials.csv` из [datasets/s-and-p-500-companies-financials](https://github.com/datasets/s-and-p-500-companies-financials).

CSV пока не приложены. Версии данных ещё нужно зафиксировать: с другими версиями результаты могут отличаться.

```bash
python -m pip install -r requirements.txt
python benford_pilot.py data results
```

Четыре графика и файл с расчётами появятся в папке `results/`. 

## Что получилось и что дальше

В первых расчётах заметно выделились годы основания городов: их первые цифры сильно отличаются от распределения Бенфорда. В остальных выборках MAD был меньше. Здесь сравнение описательное, без проверки статистической значимости. Расчёты ещё нужно повторить на сохранённых версиях данных.

В первом эксперименте смотрю, как меняются первые цифры при многократном умножении на случайные множители. Во втором на то как часто каино выигрывает против четырёх стратегий игрока. 

Дальше хочу проверить подготовку данных и попробовать анализ одного показателя отчётности, например выручки, у разных компаний. Возможное продолжение я думаю може т быть сравнить отчёты компаний до банкротства с остальными. Само отклонение от закона не означает подделку.
